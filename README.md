# LeMail Agent

**[Download LeMail Agent for Mac](https://github.com/BearRizgar/lemail-agent-releases/releases/latest/download/LeMail-Agent.dmg)** (Apple Silicon)

1. Open `LeMail-Agent.dmg`.
2. Drag **LeMail Agent** to **Applications**.
3. Open it from Applications.

Installed copies update themselves: when a new version is ready, the app shows "Ny version klar · Genstart".
